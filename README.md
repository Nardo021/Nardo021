## About Me

I'm Leo, a developer, student, and music producer based in Australia.

I build software around **AI tools, desktop applications, web platforms, Minecraft clients, launchers, and creative production workflows**. My main interest is combining **software engineering, product design, and music technology** into tools that feel practical, polished, and useful.

- Building creative software and developer tools
- Interested in AI agents, desktop apps, SaaS products, and music technology
- Working across TypeScript, React, Node.js, Java, Python and Rust
- Exploring UI design, product strategy, and music production
